# 🔐 Service Account Monitoring

## 📖 Overview

This project demonstrates how to monitor Active Directory service account password expiration using PowerShell and expose the results in Grafana.

---

## 🚀 Features

- Retrieve service accounts from Active Directory
- Calculate password expiration dates
- Export monitoring data
- Display information in Grafana dashboards

---

## 🛠️ Technologies

- PowerShell
- Active Directory
- Grafana
